# 修订说明（2026-10-20）

## 1. 我此前怎样误解了 YUVI

我把“人工个体”理解成一个有完整、可靠、可核验自传的长期系统，于是把每种内部性质换成程序能核对的显式对象：

- 心境 → 带时间的文字评价；
- 回忆 → 带引文的准确检索；
- 欲望 → 带期限的心意；
- 自主活动 → 有预算的后台任务；
- 个体 → 生活文件加模型继承。

我还把自然语言事件流当成召回效率问题，而它其实是模型怎样接触世界的认识论选择。潜在状态被排在三个月之后，门槛的判据又全是显式行为。它看不到研究对象，几乎不可能被触发。我批评 V1 让程序替模型理解，自己却让工程表示替研究对象下了定义。

## 2. 现在我理解的研究宗旨

研究一个人工系统能否形成自身的、持续演化的、部分隐含的内部组织与生活过程。重点不是“像人”，也不是“不透明”，而是：

- 不让人设、字段、任务和可观测行为预先穷尽它能成为的样子；
- 为难以定义的性质保留可运行的研究路径；
- 诚实区分“暂时替代”“没有增量”“没有意义”。

## 3. 对架构与排序的改变

- **“记录即个体”降为候选。** 保存四样：档案（世界的记录，不是它的记忆）、它重建式的记忆、潜在组织、它自己的世界。连续性在哪里，交给实验。
- **准确性只约束边界：** 身份与权限核对来源，对外效果核对授权，对别人陈述事实前先查档（规范，持续测量）。内心记录不分类型，不要证据。
- **事件流是认识论选择：** 程序只保留身份、时间、引用、先后与原文，不标情绪、意图和重要性；回忆走它自己的记忆，逐字查档是一个有意的动作。
- **心境按作用定义：** 离开上下文后仍持续；带宽低到复原不出经历；改变后续理解。第一阶段就在 V1 真实历史上离线训练写入器，第二阶段在线接入。三个月门槛取消。
- **不建三个子系统。** 我的假设（待实验）是：心境、回忆的偏置、兴趣（学习进展）可能是同一个预测组织的不同作用。
- **沙盒给自由时间，不给任务。** 私人场景只有它自己是听众，人读要走有记录的审阅。

## 4. 我仍不同意你的地方

- **读成文字不应是主要通道。** 语言模型会用人类情绪词重新解释读出，未命名的结构恰在这一步被压回词汇。我把“调节过程”放在首位：想起什么、注意什么、等多久、空闲时做什么。开放权重模型上的直接条件化是长期方向。
- **“不预设坐标”不等于没有约束。** 训练目标就是理论：选重建，得到的是记忆；选拟合文字评价，得到的是文字的另一种编码。我选“预测自身后续经历 + 慢变化 + 带宽限制”，需要你认可或替换。
- **早期沙盒里“它的兴趣”多半是模型先验。** 需要与无历史的新实例对照，并引入不来自语言模型的价值信号（学习进展）。
- **隐私只能是一种安排，对外效果不能私有。**
- **档案优先的基础设施仍然必要。** 没有它，交换、消融、重放都做不了，也分不清“它记错了”与“系统丢了数据”。

## 5. 保留、修改、放弃

- **保留：** 单次调用加工具、常驻进程、SQLite、只追加档案、`UNKNOWN`、分叉重放、数据保护、缓存布局。
- **修改：**
  - “想法即事件”只覆盖说得出的部分；
  - “想法不能证明想法”改为边界规则；
  - 漂移成为研究对象；
  - 离线生活改为自由时间；
  - 晋升门槛标为暂时替代。
- **放弃：** 完美自传式记忆、为内心记录预设类型、三个月门槛、心境等于文字评价、欲望等于心意。数值情绪动力学降为对照基线。
