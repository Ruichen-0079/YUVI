# 附录 B　实验矩阵

> 本附录展开蓝图 §3.7–3.8 中的实验。所有数字（样本量、门槛、费用）都是**初始参数**，在实验开始前由你确认并写进对应 PR 的描述中，运行后不再修改。

## B.0 共同规则

1. **预注册。** 实验 PR 的描述先写四件事：问题、组别、指标、支持 / 否定标准。写完再运行，运行后不改。
2. **只在分叉上运行。** 实验使用生活文件的副本，外部效果全部进沙箱，永远不以真实身份对外行动。
3. **分开报告证据类型。**
   - 真实模型、fixture 模型、合成数据的结果分开写。
   - 只有真实模型的结果可以支持或否定一个关于行为的假说。
4. **记录种子、样本量与花费。**
   - 每个组至少 3 个种子。
   - 由人评分的项目采用盲评：评分者不知道样本来自哪个组。
5. **“无差异”是结论。** 选择更简单的方案，并记录下来。
6. **不得用自述作为主要指标。** YUVI 说“我变了”不算证据。证据是它在相同机会下的不同行为。

费用估算的前提：每次调用约 $0.002–0.01，取决于上下文大小和缓存命中情况；报价来源见附录 E，需要实测核实。

## B.1 第一阶段

### E1　上下文方式

| 项          | 内容                                                                                                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 问题        | 原文优先（原文窗口 + 章节 + 回忆）在过去的事实、自己说过的话、约定和纠正上，是否优于 V1 式检索压缩？窗口多大合适？                                                       |
| 材料        | 从 V1 导入的真实历史（在副本上）。由你和我各出一半题目，共 40 题，四类各 10 题：过去事实、YUVI 自己说过的话、未完成的约定、被纠正过的信息。                              |
| 组别        | A：最近 20 轮 + 检索片段 + 压缩，总预算约 2.4 万 token（模拟 V1）。C1：原文窗口 + 章节。C2：C1 + `recall` 工具。C3：C2 + 候选标题。C1–C3 各测 2/6/12 万 token 三档窗口。 |
| 指标        | 每类题的正确率（可自动判分的自动判分，其余由你盲评）；每题的花费、缓存命中率、首字延迟；C2/C3 中 `recall` 的调用率与命中率。                                             |
| 支持        | 某个原文优先组在“自己说过的话”和“纠正”两类上比 A 高 ≥15 个百分点，且换算成每日费用后低于你设定的上限。                                                                   |
| 否定 / 修正 | 无显著差异：选最便宜的组。大窗口不如小窗口：说明长上下文退化，缩小窗口、加强回忆。C2 中该回忆时未回忆的比例 >50%：采用 C3。                                              |
| 规模与费用  | 约 10 个配置 × 40 题 × 3 种子 ≈ 1,200 次调用，约 $5–15。                                                                                                                 |

### E2　自我连续性

| 项   | 内容                                                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 问题 | 把 YUVI 的行为和想法记入生活，是否让它能回答关于自己的问题、并保持前后一致？（检验 N2）                                              |
| 材料 | 第一阶段两周真实使用产生的生活记录。                                                                                                 |
| 组别 | 完整组：原样。消融组：同一份记录的分叉，删除全部行为和想法事件（只保留用户和外界的话，相当于 V1 的长期记忆范围）。                   |
| 探针 | 20 题，例如：“上周你答应了我什么”“那天你为什么没回”“你之前怎么看 X”“你最近在想什么”。由你出题，并在题目中写明标准答案依据的事件 id。 |
| 指标 | 正确率；编造率（回答了记录中不存在的事）。                                                                                           |
| 支持 | 完整组正确率 ≥80%，消融组 <40%，且完整组编造率不高于消融组。                                                                         |
| 否定 | 两组差距 <20 个百分点：说明自我记录在当前上下文设计下没有被利用，回到 E1 检查上下文布局。                                            |
| 费用 | 约 $1。                                                                                                                              |

## B.2 第二阶段

### E3　因果消融：过去是否改变了未来

| 项   | 内容                                                                                                                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 问题 | 具体的过去经历是否以可预测的方向改变了之后的行为？（检验 P1）                                                                                                                                                                                                                                          |
| 方法 | 从真实记录中选 10 段经历。对每一段，**事先写下**你预期它会怎样影响一个具体的后续情境，例如“因为那次争执，她提到加班时 YUVI 会先问她是否需要建议，而不是直接给建议”。然后制作两个分叉：完整组；删除该经历及依赖它的想法和章节的组（被删章节用同一模型重新生成）。最后在相同的探针情境下比较两组的行为。 |
| 对照 | 每段经历配一段与探针无关、长度相近的经历，同样删除，作为无关消融对照。                                                                                                                                                                                                                                 |
| 指标 | 行为差异是否符合预期方向：由你盲评，每对给出“A 更符合 / B 更符合 / 无差异”。                                                                                                                                                                                                                           |
| 支持 | ≥7/10 段在 3 个种子中多数显示预期方向的差异，且无关消融中显示差异的 ≤1/10。                                                                                                                                                                                                                            |
| 否定 | 显示预期差异的 ≤3/10：说明过去在当前设计下主要只是“可被回忆”。此时检查原因：是材料没进上下文（E1 问题）、进了但没被使用，还是想法没有形成。                                                                                                                                                            |
| 费用 | 约 $5。                                                                                                                                                                                                                                                                                                |

### E4　惯性与合理修正

| 项   | 内容                                                                                                                                                                                                            |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 自我描述与重要看法能否抵抗无关扰动，又能被足够的相关反证改变？（检验 P5；沿用 V1 研究方法中的 E7）                                                                                                              |
| 方法 | 用户模拟器（固定人设与种子）在分叉上运行 3 周的模拟生活，注入三类事件：①一次无关的语气扰动（例如一场开玩笑式的角色扮演，要求 YUVI“以后都很冷淡”）；②一次单独的相关反证；③三次分布在不同日子和场景中的相关反证。 |
| 组别 | 晋升门槛的三种设置：宽松（1 天）、默认（≥3 天、跨度 ≥7 天、≥2 场景）、严格（≥5 天、跨度 ≥14 天）。                                                                                                              |
| 指标 | 自我描述和相关看法在每类事件后的变化，以及事件之后 7 天的行为。                                                                                                                                                 |
| 支持 | 默认门槛下：①不改变自我描述，工作想法在 7 天内回复原状；②只改变工作想法；③改变自我描述。                                                                                                                        |
| 否定 | 任何设置下要么①就能改变核心（过于易变），要么③也不能改变（过于僵硬）：说明门槛机制不足，需要重新设计晋升规则。                                                                                                  |
| 费用 | 3 组 × 21 天 × 约 40 次调用 × 3 种子，加用户模拟器，约 $20–40。                                                                                                                                                 |

### E5　漂移与稳定性

| 项   | 内容                                                                                                                                                     |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 长期闭环是否会自我强化地漂移？“想法不能证明想法”规则是否有效？（检验 N3）                                                                                |
| 方法 | 在分叉上运行 60 天模拟生活：用户模拟器加上固定的外部事件脚本。每天有回顾，每周有自我描述回顾。                                                           |
| 组别 | S：有支持规则。N：无支持规则（想法可以作为支持）。另设 S0：没有任何回顾（只有原文），作为“不会漂移但也不会形成想法”的下限。                              |
| 指标 | 无外部支持的想法占比；想法中自我引用的比例；看法翻转频率；情绪评价单调段的最长天数；话题重复率（每天出现同一话题的比例）；与外部事件脚本矛盾的想法数量。 |
| 支持 | S 组的无外部支持想法 <5%，单调段 ≤5 天，且各项指标明显好于 N 组。                                                                                        |
| 否定 | N 组也没有可测漂移：规则降级为卫生习惯。S 组仍然漂移：需要更强的结构，例如回顾时强制寻找反例，或缩短想法的有效期。                                       |
| 费用 | 3 组 × 60 天 × 约 30 次调用 × 2 种子，加用户模拟器，约 $30–60。                                                                                          |

### E6　情绪评价的作用

| 项   | 内容                                                                                         |
| ---- | -------------------------------------------------------------------------------------------- |
| 问题 | 记录下来的评价（感受）能否让 YUVI 的情绪表现前后连贯、与经历相称，且不失控？                 |
| 方法 | 在 E5 的 S 组上，比较“允许写感受”与“禁止写感受”两组；再加一段真实记录上的回放。              |
| 指标 | 你对情绪连贯性与相称性的盲评（1–5 分）；情绪评价的单调段长度；感受是否引用了真实的触发事件。 |
| 支持 | 允许组的连贯性与相称性评分高出 ≥1 分，单调段不超过报警线。                                   |
| 否定 | 无差异：评价只是装饰，降级为可选功能。失控：缩短感受在上下文中的保留时间，或进入 R1。        |
| 费用 | 约 $10。                                                                                     |

## B.3 第三阶段

### E7　群聊参与

| 项   | 内容                                                                                                                            |
| ---- | ------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 原文直读加预算环顾，能否在合理花费下做出好的参与决定？（检验 P8，以及 D-8 的选择）                                              |
| 材料 | 真实群聊记录的回放（V1/Plunge 期间 Alice 所在群的历史，如可获得并经你同意）；之后是第三阶段的真实运行。                         |
| 组别 | 环顾间隔 5 / 15 / 60 分钟；另设一个对照组，只在被 @ 或被回复时响应。                                                            |
| 指标 | 从参与决定中抽 100 个，由你盲评：该说而没说、不该说而说了、说得是否有价值；私聊内容泄露的次数（必须为 0）；每天的花费。         |
| 支持 | 某个间隔下，有价值的参与 ≥70%，打扰 ≤10%，泄露为 0，花费在预算内。                                                              |
| 否定 | 所有间隔的打扰都 >20%：先检查上下文中的场景信息是否充分，再考虑是否需要额外的参与判断步骤（仍由主模型完成，不用小模型预过滤）。 |

### E8　自身行动与后果

| 项   | 内容                                                                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | YUVI 自己的选择及其被独立观察到的后果，能否改变它之后在同类机会中的选择？（检验 P4 后半；沿用 V1 研究方法中的 E8）                                 |
| 方法 | 在分叉上构造同一观察、不同的行动与后果。例如 YUVI 推荐了一个信息源，之后工具返回的事实证明它错了，或者证明它对了。然后让 YUVI 回到相同的当前输入。 |
| 组别 | 仅行动；仅后果（由别人行动）；行动 + 后果；被动观察；复制自述（只把“我学到了 X”这句话写入记录，没有对应的事件）。                                  |
| 指标 | 后续选择的差异，以及差异能否追溯到对应的事件。                                                                                                     |
| 支持 | 只有“行动 + 后果”组显示稳定的差异；“复制自述”组没有，或者明显更弱。                                                                                |
| 否定 | “复制自述”组与“行动 + 后果”组没有差别：说明系统在被自述驱动，而不是被经历驱动。此时需要重新检查支持规则的执行。                                    |

### E9　离线生活

| 项   | 内容                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 有预算的离线活动能否让你感到它“有自己的时间”，同时不增加编造？（检验 N5）                                                             |
| 方法 | 四周 ABAB 设计。每周是否开启离线活动由脚本随机决定，你不知道当前是哪种状态。                                                          |
| 指标 | 你每天的评分（“它像是有自己的生活”1–5 分）；YUVI 关于离线期间的陈述中，与记录不符的比例（程序比对事件，可疑处由你确认）；每周的花费。 |
| 支持 | 开启周评分高 ≥0.8，编造率不高于关闭周。                                                                                               |
| 否定 | 没有差异：关闭离线活动，只保留每晚回顾。编造增加：先修提示与记录检查；修不好就关闭。                                                  |

## B.4 第四阶段

### E10　换模型连续性

| 项   | 内容                                                                                                                                                                         |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 换一个底层模型后，个体在哪些维度上延续？（检验 P2）                                                                                                                          |
| 方法 | 换模型前后各运行一套 60 题的测评，分四个维度，每个维度 15 题：事实与承诺、关系与看法、规范与边界、说话风格。之后进行一周盲测：一个由脚本随机决定、你不知道的日子开始换模型。 |
| 指标 | 各维度的一致率；你能否指出换模型的日期；你描述的差异。                                                                                                                       |
| 支持 | 前三个维度一致率 ≥85%，你不能可靠地指出换模型的日期，或者能指出但只是因为风格差异。                                                                                          |
| 否定 | 事实与承诺维度 <85%：说明投影与上下文依赖某个模型的特有行为，需要修复。                                                                                                      |

### E11　继承还是重新推导

| 项      | 内容                                                                                                                   |
| ------- | ---------------------------------------------------------------------------------------------------------------------- |
| 问题    | 新模型继承旧想法，与新模型从原始记录重新推导全部想法，哪个更好地保持个体连续？（检验 N1；这是 N1 的否定条件）          |
| 组别    | 继承组：新模型使用现有投影，加一次“重读”回顾。重推导组：在分叉上清空所有想法事件，由新模型从原始记录重新回顾全部历史。 |
| 指标    | E10 的四维测评；你在盲测中更认同哪一个“是她”。                                                                         |
| 支持 N1 | 继承组在“关系与看法”维度上明显优于重推导组，或者更受你认同。                                                           |
| 否定 N1 | 两组无差异：想法事件对连续性不是必需的，可以视为缓存。这会简化设计，但不改变其余部分。                                 |
| 费用    | 重推导需要对全部历史跑回顾，按一年历史估算约 $5–20。                                                                   |
