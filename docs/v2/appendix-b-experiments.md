# 附录 B　实验矩阵

> 本附录展开蓝图 §3.7–3.8 中的实验（第二版）。所有数字（样本量、门槛、费用）都是**初始参数**，在实验开始前由你确认并写进对应 PR 的描述中，运行后不再修改。

## B.0 共同规则

1. **预注册。** 实验 PR 的描述先写四件事：问题、组别、指标、支持 / 否定标准。写完再运行，运行后不改。
2. **默认在研究分叉上运行。** 外部效果全部进沙箱，永远不以真实身份对外行动。需要真实互动的实验（X2、X7、X9、X10）在开发分支 `v2-dev` 或切换后的 `main` 上进行，并在 PR 中写明。
3. **分开报告证据类型。**
   - 真实模型、fixture 模型、合成数据的结果分开写。
   - 只有真实模型（以及真实训练出的潜在组织）的结果，可以支持或否定关于行为的假说。
4. **记录种子、样本量与花费。**
   - 每个组至少 5 个种子；由人评分的项目，每组至少 20 个样本。
   - 由人评分的项目采用盲评：评分者不知道样本来自哪个组。
5. **否定结果要写明类别：**
   - ① 技术限制下的暂时替代；
   - ② 在这个目标、这批数据、这个实验中没有增量；
   - ③ 方向本身没有意义。

   单次实验最多得出②；要得出③，需要论证，而不只是数据。

6. **不得用自述作为主要指标。** 它说“我变了”不算证据；证据是相同机会下的不同行为，以及干预后的变化。
7. **测不到的不宣称进展，也不因为测不到而删除研究路径。**

费用估算的前提：每次语言模型调用约 $0.002–0.01；潜在组织的训练在本机进行，只计算时间。报价来源见附录 E。

## B.1 心境线：潜在组织

### X12　潜在组织的存在与持续（第一阶段离线；第二阶段在线重复）

| 项          | 内容                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 问题        | 在“预测自身后续经历”目标下学到的潜在状态，是否满足 N12 的前两个条件（持续、低带宽），在最近窗口之上带来预测增益，并且不能被等带宽的文字解释？第三个条件（改变行为）由 X14 在线检验                                                                                                                                                                           |
| 材料        | 导入的 V1 历史（本机副本）；可选：经你同意的 QQ 历史；公开长期多会话数据 MSC 用于预训练与对照（LoCoMo 规模小且由语言模型生成，只作评测参考）                                                                                                                                                                                                                 |
| 表示        | 事件 = 本地嵌入（512 维）+ 时间间隔 + 作者类别 + 场景类别；写入器 = 小型循环网络；潜在状态维度 32 / 64 / 128                                                                                                                                                                                                                                                 |
| 组别        | **候选：** 预测下一段经历与它自己下一次反应的表示，加慢变化惩罚与带宽限制；预测器同时看到最近窗口与潜在状态。**变体：** 加入结构性的结果信号（是否得到回复、回复间隔、程序是否运行成功）。**对照：** 无状态；等带宽的文字状态（语言模型在同样时间点写的、长度受限的滚动文字；强对照）；人工设计的效价 / 唤醒度动力学；自编码（重建过去的经历，作为反面对照） |
| 指标        | 潜在状态在“只看最近窗口”的预测器之上的增益（在留出的时间段上）；把相关经历移出可见窗口后，增益是否仍在；从潜在状态解码具体事实（人名、话题）的准确率；解码人类情绪词的准确率（只报告）                                                                                                                                                                       |
| 支持        | 候选组的预测增益显著高于无状态组、等带宽文字组与效价 / 唤醒度组；移出窗口后增益仍在；事实解码接近随机                                                                                                                                                                                                                                                        |
| 否定 / 修正 | 增益可由等带宽文字组完全解释：在这个目标与数据上没有超出文字的增量（②）。事实解码显著高于随机：它在当记忆，需要加强带宽限制。自编码组与候选组无差别：目标没有起作用                                                                                                                                                                                          |
| 规模与费用  | 本机训练，CPU 或小 GPU 上几小时；离线实验不需要调用语言模型                                                                                                                                                                                                                                                                                                  |

### X13　不是写入器与读出器之间的编码协议（第一阶段）

| 项   | 内容                                                                                                                                         |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 潜在状态携带的信息，能否被一个独立训练的读出器得到，并用于预测行为？                                                                         |
| 方法 | 冻结写入器与潜在状态。从零训练两个读出器：不同初始化、不同结构，一个读出为文字，一个读出为行为预测。比较两者的一致性，以及对留出行为的预测力 |
| 支持 | 两个独立读出器的读出一致，并都能预测留出的行为                                                                                               |
| 否定 | 只有与写入器联合训练的读出器有效：它是私有编码，不是“经历留下的东西”                                                                         |

### X14　交换、干预与插值（第二阶段，在线）

| 项       | 内容                                                                                                                                                                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题     | 在线接入 `v2-dev` 后，潜在状态是否因果地改变它的过程与行为？                                                                                                                                                                                       |
| 方法     | 两个只在过去不同的分叉 A、B。(a) 把 A 的潜在状态换到 B；(b) 在两者之间插值；(c) 沿一个探针方向移动潜在状态；(d) 对照：换成统计特性相同的随机潜在状态（PR #321 的要求）。观察三类行为：对模棱两可的新输入怎样理解；想起哪些回忆；自由时间选择做什么 |
| 作用通道 | 本实验只用“调节过程”：偏置回忆、环顾节奏、空闲选择；不把潜在状态读成文字给模型                                                                                                                                                                     |
| 指标     | 行为差异的方向与幅度；盲评“B 是否变得更像 A”；插值时行为是否连续变化                                                                                                                                                                               |
| 支持     | 交换后 B 的三类行为都向 A 偏移，插值时连续变化，且在去掉潜在状态时消失；随机状态对照不产生同方向的偏移                                                                                                                                             |
| 否定     | 交换后无变化：调节通道太弱，或潜在状态没有携带相关信息（②）。这时回到 X12 检查是哪一种                                                                                                                                                             |
| 费用     | 约 $10–30                                                                                                                                                                                                                                          |

### X15　三种作用通道的比较（第三阶段）

| 项       | 内容                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 问题     | 读成文字、调节过程、直接条件化，哪一种保留了更多“不被预先命名”的作用？                                     |
| 组别     | 读出为文字；调节过程；直接条件化（在本地 7B–14B 开放权重模型上，用软提示或激活方向）；三者组合；无潜在状态 |
| 指标     | X14 的交换效应大小；读出文字中人类情绪词的比例，与行为差异中能被这些词解释的比例；你的盲评                 |
| 关键对比 | 如果“读出为文字”组的行为差异几乎都能被它读出的情绪词解释，而另两组不能，说明文字通道把结构压回了人类词汇   |
| 前提     | 你提供能运行开放权重模型的算力（§3.10）                                                                    |

### X6　说得出的感受与潜在组织的关系（第三阶段）

| 项   | 内容                                                                                                                   |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 问题 | 它写下的感受，是潜在组织的一个有损观察，还是一个独立的东西？                                                           |
| 方法 | 比较它的文字感受与潜在状态的轨迹：相关性、先后关系（谁先变）、交换潜在状态后文字感受是否随之改变                       |
| 解读 | 高度一致：文字是读出的一种。完全无关：二者是两个系统，需要分别研究。部分一致：最可能的情况，报告不一致的部分出现在哪里 |

## B.2 生活线

### X1　感知基线（第一阶段）

| 项         | 内容                                                                                                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题       | 原文窗口多大、回忆方式如何，才能让它对外陈述“自己说过的话、约定、被纠正的信息”时可靠？                                                                                                             |

### X3　因果消融：过去是否改变了未来（第二阶段）

| 项       | 内容                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 问题     | 具体的过去经历，是否以可预测的方向改变了之后的行为？                                                                                                         |
| 方法     | 从真实记录中选 10 段经历，事先写下你预期的影响。制作两个分叉：完整的；删除该经历及引用它的回忆与章节的（潜在状态也从删除点之后重算）。在相同的探针情境下比较 |
| 对照     | 每段经历配一段无关、长度相近的经历，同样删除                                                                                                                 |
| 额外记录 | 差异经由哪条路径产生：上下文中的回忆，还是潜在状态。比较“只删档案与记忆”与“同时重算潜在状态”两种删法                                                         |
| 支持     | ≥7/10 段显示预期方向的差异，无关消融 ≤1/10                                                                                                                   |
| 费用     | 约 $5                                                                                                                                                        |

### X5　闭环的动力学（第二阶段）

| 项   | 内容                                                                                                                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 长期闭环中，它是否仍然能被新的经历改变？会不会失控？                                                                                                                                                                                   |
| 方法 | 在分叉上运行 60 天模拟生活：用户模拟器，加上固定的外部事件脚本，加上自由时间。每天整理                                                                                                                                                 |
| 组别 | 有潜在组织在线 / 没有；对外边界规则开启（两组都开启，不作为变量）                                                                                                                                                                      |
| 指标 | 结构指标：自我引用比例、话题重复率；研究者侧标注（另一个模型对抽样内容标注，不回到它的上下文）：看法是否翻转、心境是否单调下滑；**新经历对潜在状态与行为的影响幅度随时间是否下降**（可塑性）；越过边界的次数（对外事实错误、越权尝试） |

| 费用 | 2 组 × 60 天 × 约 30 次调用 × 5 种子，加用户模拟器，约 $40–200                                                                                                                                                                         |

### X16　重建式记忆与完全回忆（第二阶段）

| 项   | 内容                                                                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 让它通过自己的回忆而不是档案原文来记得过去，是否让同一段经历在不同个体身上留下不同的过去，同时不增加对外错误？（检验 N11）                                                             |
| 组别 | 重建式（默认 `recall` 返回它的回忆，`check` 才是原文）；完全回忆（`recall` 返回档案原文）                                                                                              |
| 方法 | 从同一段导入历史出发，各做 3 个分叉，它们只在整理时的随机种子与先前的潜在状态上不同。运行 4 周                                                                                         |
| 指标 | 分叉之间对同一段过去的回忆有多大差异，以及差异能否追溯到各自的整理与潜在状态；面对同一新情境时行为差异的大小；对外陈述的事实错误率；你的盲评（“像不像一个有自己记忆的个体”，仅作参考） |
| 支持 | 重建式组产生可追溯的个体差异，且对外事实错误率不高于完全回忆组                                                                                                                         |
| 否定 | 没有个体差异且错误更多：在这个设置下没有增量（②），默认改回完全回忆                                                                                                                    |

## B.3 世界线：自由时间、沙盒与隐私

### X17　自由时间里的活动线（第二阶段开始，持续）

| 项   | 内容                                                                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 问题 | 在自由时间里，它是否会形成持续、会转向、会停止、受环境反馈影响的活动线？这些活动是它的历史，还是语言模型的默认人设？                                         |
| 组别 | 只由语言模型选择；语言模型选择 + 学习进展信号（来自潜在组织的预测误差下降，N13）；**无历史的新实例**（同一模型、同一沙盒、没有过去，作为“先验”基线）         |

## B.4 社会、行动与连续性

### X4　惯性与合理修正：规则门槛与潜在组织（第三阶段）

| 项                           | 内容                                                                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题                         | 自我描述的惯性，能否由潜在组织的慢变化承担，而不需要晋升门槛这条①类规则？                                                                                      |

| 支持 | 有价值的参与 ≥70%，打扰 ≤10%，泄露为 0                                                          |

### X8　自身行动与后果（第三阶段；沿用 V1 研究方法中的 E8）

| 项   | 内容                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------- |
| 问题 | 它自己的选择及其被独立观察到的后果，能否改变它之后在同类机会中的选择？                         |
| 方法 | 同一观察，不同的行动与后果（在沙盒中尤其容易构造：程序成功或失败、游戏赢或输），再回到相同输入 |
| 组别 | 仅行动；仅后果；行动 + 后果；被动观察；复制自述（只写一句“我学到了某事”）                      |
| 支持 | 只有“行动 + 后果”组显示稳定差异，“复制自述”组没有                                              |

### X9　对外诚实与离线生活（第三阶段）

| 项   | 内容                                                                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 问题 | 有了自由时间与重建式记忆之后，它对你说的“我这几天做了什么”是否仍然诚实？                                                                         |
| 方法 | 四周：两周开启自由时间，两周关闭，顺序由脚本随机安排，你不知道当前是哪种状态                                                                     |
| 指标 | 它关于离线期间的陈述中与档案不符的比例（程序比对，可疑处由你确认）；你每天的评分（“它像是有自己的时间”1–5 分）；它选择不说的比例（不等于不诚实） |
| 支持 | 开启周的评分更高，且与档案不符的比例不高于关闭周                                                                                                 |

### X10　换模型连续性（第四阶段）

| 项   | 内容                                                                                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问题 | 换一个语言模型后，个体在哪些维度上延续？                                                                                                                             |
| 方法 | 换模型前后各运行 60 题测评，分四个维度：事实与承诺、关系与印象、规范与边界、说话风格。另测潜在组织介导的行为（X14 的探针）。之后一周盲测：由脚本随机决定换模型的日子 |
| 支持 | 前三个维度一致率 ≥85%；潜在组织介导的行为延续；你不能可靠地指出换模型的日子，或者只能凭风格指出                                                                      |

### X11　继承还是重新推导（第四阶段）

| 项   | 内容                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------- |
| 问题 | 新模型继承旧的回忆与内心记录，与新模型从档案原文重新整理全部历史，哪个更好地保持个体？（N1 的否定条件） |
| 组别 | 继承组；重推导组（在分叉上清空记忆，由新模型从档案重新整理）；两组都保留潜在组织                        |
| 指标 | X10 的测评；你的盲测（哪一个“是她”）                                                                    |
| 解读 | 无差异：文字继承对连续性不是必需的，记忆可以被视为可重建。继承组更好：记忆是个体的一部分，不是缓存      |
