# 经历、观察与授权分离

2026-10-17 后续：[Durable Observation 提交合同与真实 Vision](../durable-observation-retrieval/README.zh.md)。A9 与有界报告同事务，保留 UNKNOWN/TTL/擦除；检索质量及 R5 整体门槛仍开放。

**阶段性交付，不能据此切换真实 Alice，也不代表 Memory R5 完成。** 基于 #327 `ce5e078`，依赖 #326→#325→#324→#323→#322 全部保留。独立工作树、独立 PostgreSQL schema、合成 Person/Persona/图片/文件；没有部署、迁移或重启 Alice，没有 QQ 测试消息。

本批改变三个实际行为：

1. PostgreSQL Authority 模式下，可信用户输入在 Server ingress 同事务写入 Journal、Conversation 与摄取决定。助手成功、沉默、失败、取消不是其长期学习机会的前提。现有持久 Worker 发现 `accepted-user:<eventId>`，继续使用 R5 任务、租约、来源校验、提交及恢复；没有第二条队列。聊天不等待远端提取。
2. 已正式保留的图片/文件观察可跨轮、跨进程读取；观察属于 Provider 报告，执行是否 APPLIED 来自 A9，Cognition 是否完成是第三个事实。保留默认关闭，原图需要额外开启。过期/删除/来源授权失效后，模型必须重新取得合法来源，不能通过旧助手摘录获得内容。
3. 普通知识更新产生 `STALE` 快照，不再冒充权限撤销。Body 使用捕获快照并收到真实的新鲜度提示；当前 Host、Person 绑定、Persona 所有权和能力授权仍独立检查。控制者可撤销执行中的单文件授权；既有 APPLIED/UNKNOWN 不会被改写。

**观察完整性尚有正式阻断：** A9 保留执行真相，内容作为单独的限期投影在 A9 成功后保存。若进程恰在终态提交与报告保存之间崩溃，或报告写库失败，动作仍可能 APPLIED，但报告不可恢复；不能重试外部动作来猜测原结果。当前没有“报告已持久成功”回执，也没有 durable 待保留报告恢复机制。`observations/v1` 只列已保留报告，空集合不证明没有执行过动作。此问题阻止将 B 宣称为全部故障阶段可靠；下一纵向阶段应统一结果保留提交边界，不能另建动作账本。

另一个保留的真实反例：初次英文组合查询未选到已持久编辑器事实；该事实**没有进入最终 Gate/Body**。本批没有修复整个文本/向量召回系统，不能用后来的中文单项成功掩盖它。
