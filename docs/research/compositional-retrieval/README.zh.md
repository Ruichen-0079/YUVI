# 组合检索与回答证据忠实度

基线 #330 `28361e0`，独立分支 `feat/compositional-memory-retrieval`。本批不改变 Authority 历史或 A9/Observation 提交合同，不接触真实 Alice。

首先冻结 [Ground Truth](experiments/ground-truth.json)：合法协议来源形成的确定性存储样本与真实模型语义实验分开。数据包含纠正、冲突、支持、独立 Person/Persona、UNKNOWN、高相关干扰及 development/holdout 查询。事实中的值不会进入检索规划请求。手工 needs 只用于确定性协议对照，不能作为模型理解能力的证据。

归因顺序：来源接纳→权威记录/现行状态→计划来源片段→各通道候选→覆盖选择→Gate/Body 实际 Context→最终回答。跨会话模型实验须正式失效合成 L1 并重启，不靠旧对话补答案。

## 已交付的生产行为

正常 Server/Character 的 Memory 检索现在可以按至多五项需求分配候选，**Runtime 最终仍取五条，没有扩大默认 top-K**。一次可选规划同时做需求拆分、短检索词和中英翻译；模型只看到用户问题，不看到目标答案或候选。每个需求必须引用问题中准确、按序、不重叠的片段。片段验证只证明来源，不证明翻译或意图理解永远正确。原始查询始终保留；规划失败、超时或格式错误明确降级，真正撤权继续 fail-closed。付费开关仍默认关闭。

每需求独立召回后先保留其首选，再进行去重和有限补充。真实实验曾发现“负责人”首选已召回，却因另一个需求选中了其低排名邻居而被误判覆盖；`ade9bbf` 改正此分配错误。Retrieval Evidence/Typed Client 同时提供 `preferredId`、`preferredSelected`、通道候选、状态、模型/usage 和词项截断标志。**SELECTED_CANDIDATE 是候选可用性，不是语义蕴含证明。**

中文词项现在包含一般 Han 子词后备，不硬编码茶叶、编辑器等词汇。历史混合标识中的中文片段和下划线标识也进入派生索引。中英没有共同词项时，文本本身不能“翻译”：依赖显式规划或已有真实向量模型。向量也可能被相似干扰占据，因此不能将整句 ANN top-K 当作组合覆盖。

报告中的正确命题并不保证正确回答。正文量值比较增加先列报告标签/值的约束；Memory 使用同一预算内的需求—来源引文结构，保留命题归属及 current/conflicted。没有新增回答裁判模型、Memory 队列、账本或 Authority 历史。

| 冻结 PostgreSQL + 真实 Qwen 512D 数据 | 有可读事实的 10 个问题，整句 Vector 6/10、全局 Hybrid 3/10、全局展开 Hybrid 6/10、新需求选择 10/10 完整已知证据覆盖；详见下文指标边界 |
| 冻结真实 Qwen 视觉报告→真实 Character | 同一报告，两组各 10 条：旧组一次同时称 A 最矮且 B 比 A 矮；新组未出现。背面颜色均未知。这是表达重放，不是新的视觉准确率验收 |

Ground Truth 在 `080c9a3` 冻结。手工计划矩阵证明选择/索引合同，真实语义计划与最终答案另由正式入口证明。12 个冻结问题中两个是全未知权限控制，不能放进已知事实召回分母；另有一个部分 UNKNOWN。表中的完整覆盖指**存在且有权读取的事实**，不把 UNKNOWN 算作找到事实。当前相关性 precision 宏平均约 0.52，未知需求也可能得到无关 ANN 首选（3/3 个未知槽），说明候选可用性仍不能充当语义证据。

真实模型仍保留第一人称归属错误；未普遍解决回答忠实度。旧组和新组的自然纠正都捕获两命题中一条写入成功、另一条重试耗尽的 PARTIAL，归因为形成/写入层，不计作检索失败。当前事实已正式存在的组合对照独立进行；没有放松 admission、来源或幂等。

因此可关闭本冻结集的**已知可读事实覆盖回归**，不能关闭通用语义覆盖、无关候选/UNKNOWN 判定、广泛回答忠实度或 R5 整体验收门槛。
