**阅读方式：** 按 PR 编号顺序（即时间顺序）分 7 批生成摘要，逐批阅读并写研究笔记。没有把标题当作内容。对“声称”与“证据”分开记录：PR 描述是当时参与者（多为编码代理）的主张，只有可复核的测试、实测记录或后续 PR 的确认才计为证据。

**归类是研究判断，不是事实。**

- 主题由规则（标题/分支关键词）给出，再逐条人工修正。
- 研究归类全部经过人工判断，每个 PR 都有显式归类（覆盖表见 `classify.py`）。
