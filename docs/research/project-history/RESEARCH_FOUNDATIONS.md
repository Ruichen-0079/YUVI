# YUVI 研究基础：值得继承的思想与证据

> 研究日期：2026-10-19。本文从[项目史](PROJECT_HISTORY.md)与 [PR 索引](PR_RESEARCH_INDEX.md)中提炼可以离开旧仓库独立成立的部分。
>
> 标注：**[A]** 研究命题；**[B]** 有工程证据；**[C]** 未验证；**[D]** 已被证伪或取代。未写明来源的判断是本研究的推论。

## 0. 为什么开始 YUVI（以证据所及为限）

- 仓库最早的自我描述（05-10）是“受 Project AIRI 启发的本地 AI 伴侣运行时”。
- 08-28 起，目标被明确区别于助手与智能体框架：一个持久、会沉默、身份不随模型更换的本地伴侣。
- 09-12 的计划写明，地基完成后要转入以“记忆动力学”为核心的研究（雏雁/鸿雁杯）。
- 09-19 写下：要的是一个“生活在自己生活之中、而不是反复查询它”的人工个体。

可以确认的初衷是：**一个 AI 系统能否拥有一段会改变它自身的经历史，并在更换底层模型后仍然是同一段经历的延续。** 更早的动机如果存在，不在仓库中。

## 2. 架构原则：可以跨实现继承的部分

这些原则不依赖任何旧代码，每条都有历史失败或成功作为理由。

1. **记录与解释分层。**
   - 一层是只追加的“发生了什么”：谁、何时、在哪个场景、回复谁、引用什么、附件是什么、来源与权限、是否真的送达。
   - 另一层是派生解释：由模型产生，带来源、带版本、可纠正，并能随来源失效而失效。
   - 理由：#9 的证据模型；A10.1a 用桩模型复现的“LLM 抽取路径会把编造偏好写成用户说过”；R5 命题级纠正。
2. **归因是一等公民，不确定就明说。**
   - 作者/断言者、所涉主体、听众、来源观测、事件时间与记录时间、是自己真正说出的还是只是草稿，彼此分开。
   - 无法解析的身份写成“未知”，不猜测，也不写入长期记忆。
   - 理由：Atom 12/13；QQ 研究；线性上下文的 `SELF_SENT`/`SELF_DRAFT`。
3. **模型看到的是可读的生活现场，而不是管理用 JSON。**
   - 机器在下层保持精确，模型在上层接收按时间排列、带作者的原文与感知。
   - 理由：北极星 §3；10-08 的真实请求从 9,885 字符降到 4,642 字符；#323、#327 恢复原文后事实不再丢失。
4. **不伪造确定性。**
   - 结果未知就是 `UNKNOWN`；失败不等于沉默；没有回执不能说“记下了”。
   - 理由：阶段 1 的 P4 投递账本与 A9 的 effect 账本；审计 F6（协议失败被伪装成沉默）；#324 中模型误称“已记下”。
5. **纠正是常态而非异常。**
   - 新认识取代旧认识，但保留历史与理由，依赖它的派生物随之失效。
   - 理由：R4 之前自然语言纠正产生零候选；R4/R5 之后重启仍使用纠正值。
6. **“模型提议、系统提交”只适用于外部事实、身份绑定和外部效果。**
   - 这条原则防止了自我确认循环和伪造身份，是必要的。
   - 但把它推广到模型对自身经历的解释与内部状态，就会让系统永远没有“理解”，只剩证据。P8 和 Profile 都停在这一步：有证据，没有理解的生产方，也没有读方。
   - 内部解释应允许以“带来源的、可修正的假设”存在。
7. **机械可替换，经历不可替换。**
   - Provider 和模型只是基础设施；身份存在于记录与派生状态中。
   - 派生状态要与产生它的解释器版本一起保存，换模型时才知道哪些理解需要重新评估。
8. **最小充分机制，加上可证伪的比较。**
   - 09-24 的比较设计是值得保留的实验工具：B0（原始长上下文）、B0p（加来源）、B1（现行系统）、B3（强显式选择）、O_text/O_selection（神谕上限）、消融、预注册、失败判据。
   - 但门槛应当用来**比较**替代方案，而不是在比较之前**禁止**它们。

## 4. 有长期价值的实验结果（含负面结果）

**负面结果：**

1. **规则预解释会系统性地出错。** 关键词情绪把“解释 anxious 这个词”判为焦虑；“Don't forget”被程序理解成删除；控制协议失败被合成为“成功的沉默”；桌面回合被预设为“在对 YUVI 说”。
2. **截断与摘要会丢事实。** 800 字逐条截断、`length` 整体拒绝、SSE 心跳丢正文，都直接造成记忆失效；恢复原文即恢复。
3. **LLM 抽取路径可以伪造归因。** A10.1a 用编造偏好的桩模型复现：该路径会把它写成带伪造来源、归为“用户”的核心记忆（测试复现，未证明生产中发生过）。任何派生解释都必须能指回精确的原文片段。
4. **为模型弱点设计架构会固化弱点。** V4 不能稳定输出控制前导，于是出现了 70B 决策模型 + 写作模型的双模型主动路径；后训练模型尚未出现，就先建了一整套 Character Harness。
5. **没有消费者的结构不会自己变成能力。** 合同包直到 #283 才接线；Profile 物化后无人读取；Dream 的 idle 触发在生产中从未发生。
6. **小型路由模型难以兼得高召回与过滤收益。** QQ 研究中本地 4B 能保守放行，却几乎不过滤；8B 有区分度但对提示敏感。路由器也看不到主 Character 的理由。

**正面或可用的结果：**

7. **“结构化 envelope + 带作者的原文”在真实回放中可行。** 上下文减半，多数直接呼唤判断正确，但旁听插话判断仍不稳定。
8. **真实模型实验的金钱成本可以忽略。** 每组实验数十到数百次调用，费用以美分计。限制实验数量的不是费用，而是代理环境中缺少获准的模型凭据（#335–#337 中“真实模型 B 阻断”）。

## 5. 尚未解决的研究问题

按“没有答案就无法前进”的程度排序。这只是问题排序，不是实施计划。

1. **什么承载倾向？** 文本状态、持续的内部状态、模型参数，三者都可能；判别它们需要在相同预算下比较 B0p/B3 与带状态的方案，并做状态交换与消融。至今一次都没有做过。
2. **解释如何形成、修正、衰减？** 是封闭标签加确定性积分，还是开放词汇的“暂定认识”加证据回查？后者更接近 P3、P5，但漂移和自我确认风险更高。
3. **怎样遗忘而保留影响，同时仍可纠正、可删除？** 删除与连续性在隐私层面有真实冲突（research-methodology R5）。
4. **怎样测量“过去改变了未来”而不被自我叙事欺骗？** E3（因果消融）、E7（惯性与合理修正）、E8（自身行动与独立后果）是现成的问题陈述，缺的是长期轨迹生成器、回放设施和真实使用数据。
5. **慢变量内部调节是否有增量价值？** 相对于显式承诺 + 检索，它能否在注意分配、主动阈值、认知投入上产生可预测、可消融的差异？这个问题从未被允许检验。
6. **多人社会场景中，主模型直接阅读完整原始流的成本与质量曲线如何？** 何时才真正需要路由？
7. **跨模型的连续性落在哪些维度上？** 事实/义务、关系/偏好、规范、风格（model-replacement.md 的四轴）；理解类派生物是否需要随解释器版本重新评估？

## 6. 如果重新开始：继承什么，不继承什么

**作为知识继承：**

- 第 2 节的八条原则，以及第 4 节的负面结果；
- 线性、带作者的模型上下文格式（`character-linear-context.v1` 的思想，而非代码）；
- 纠正语义（取代但保留历史、依赖失效）与 `UNKNOWN` 效果语义；
- 09-24 的比较实验设计与失败判据，作为工具而非禁令；
- 用真实模型做小成本实验并记录费用的做法；把合成负载证据与模型质量证据分开报告的纪律；
- 单机 Linux 运行、持久化、身份激活与冷恢复的操作知识（#336/#337 的工具与矩阵）。

**不应作为未来约束：**

- `AGENTS.md` 第 4、5、12 条（“不得直接给原始记录”“必须压缩重构”“生产不得依赖 PostgreSQL/Node”）及其默认 Provider 列表；
- Mem0、L0/L1/L2 分层与 Dream 规则整合；
- Character/Cognition 双模型分工、Character ABI/Harness、gate + 正文的两次调用；
- 全局化的“唯一权威”表与 atom 粒度的开发方式；P6 冻结；
- 09-24 的禁止清单（无 Life Layer、无任何心理标量），它们是待检验的路线选择；
- 行为规范/偏好数据集格式与阶段 8–13 训练路线；
- Tauri、Supervisor、systemd、Live2D、TTS/STT 栈。这些是“身体”的一种实现，可保留为产品选择，但与研究命题无关。

**需要你重新做决定的：**

- 是否让“暂定的、带来源的内部解释”成为一等对象（P3/P5 与原则 6 的交点）；
- 研究阶段从哪个命题开始（P1 的因果检验最直接，现有记录设施已足以支撑起步）。
