# Memory R5：PostgreSQL 权威存储纵向切片

**R5 尚未完成，不能据此部署或迁移真实 Alice。** 本阶段建立可独立运行的权威历史、命题投影、持久语义任务、索引恢复和产品读取 API。它替换新后端中的结构性错误；旧 Mem0 后端仍保留兼容，因此全产品的硬性门槛仍开放。

基线为 R4 PR #324 `8c6eb38178804f28d3d552cfcdf77eb692a2c9ae`，依赖未合并的 #322 → #323 → #324。生产提交 `c33214c`；worker Persona 边界提交 `0bd0e0a`；对应回归分别独立提交。开发位于独立 worktree，未合并、部署或迁移真实数据库。2026-10-11 续跑时主机已由外部重启；Alice 仍是独立安装进程，当前路由再次核对一致。实验只使用合成 Person、Persona、Journal namespace、数据库及独立端口。

## 本阶段结果

| 能力               | 实际交付与证据                                                                           | 验收范围                                                    |
| ------------------ | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 权威历史与当前认识 | PostgreSQL 原子追加、命题级关系、同事务投影/计数/版本；A 保留历史、B 当前有效            | 独立新后端已使用；完整来源审计仍不足                        |
| 主动语义形成       | 每个合法完成来源有评估机会；模型前持久状态；新后端没有关键词语义 veto 和规则 fallback    | 正式 Finalized 路径；匿名 `/message` 的 Host 身份接入未完成 |
| 精确纠正/冲突/强化 | 指代与英文纠正、共享来源独立命题、双方冲突保留、强化证据边                               | 有真实模型诊断样本；不代表多年可靠性                        |
| 恢复               | PostgreSQL 立即停止中断事务及成功回执后重启；未知结果对账；worker 租约、索引失败/修复    | 已覆盖一组关键故障；完整故障矩阵未完成                      |

| 迁移               | 250 条旧 DTO：100 条检查点停止、新进程补至 250、再次执行不重复；未知时间拒绝且可观察     | 未验证真实旧 Mem0/Profile/派生资产迁移                      |
| 产品 API           | 7 个 v1 读取路由、Client、实际 PG 路由测试和完整 Server HTTP 读取                        | 本地 operator 权限；完整 Retrieval Evidence/关系图/指标开放 |
| 工程验证           | `pnpm check`、build、全仓 test；43 项指定 PG 回归、3 组实际 PG 路由回归；CI 增加必跑步骤 | CI 结果以 PR 实际检查为准                                   |

最终冻结模型复测中 GLM 发生两次 429 和一次网络失败。系统保持可重试失败，没有报持久成功。实验显式改用现有 DeepSeek 路由做提取，按原任务/Journal 恢复；A→B 更新完成，茶叶命题保持有效，新会话与新进程均回答 B。它证明这一纵向路径和恢复行为，不证明所有自然语言或正常 Alice 端到端体验已完成。
