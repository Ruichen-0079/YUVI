Status: A0–A6, A7.1, A7.2, A8.1, A8.2a and A8.2b **IMPLEMENTED REALITY**; aggregate A8.2, A8.2c–A8.2f and A9–A12 **PLANNED ENGINEERING**. The release definition below is a **PRODUCTION ARCHITECTURE DECISION**, not a claim of release completion. The legacy filename is retained for links; “platform completion” is no longer this release's scope.

## Closure definition

v0.1.3 closes when a restart-durable, provenance-aware journal and outbox preserve causal evidence across one Runtime semantic path, every relevant effect is admitted and accounted for without fabricated certainty, all new evidence-backed consumers retain committed lineage, and the same contracts pass fault-injected synthetic-surface CI plus a real QQ/Snowluma probe. A12 must publish its tested protocol/version and limits. Completion is blocked if either real-surface evidence or crash/concurrency evidence is missing. It does not require inferred dispositions, learned state or three-platform certification.

Six invariants are the release contract:

- **I1 Durable before effect:** commit accepted input before downstream semantic processing; commit authorized INTENT/outbox and ATTEMPT before an external effect may start. Visible progressive output cannot outrun durable evidence. Journal unavailability fails closed for new effects.
- **I2 One logical intent:** stable scoped key and payload identity admit one intent; retries/duplicates do not mint another logical action. This is not exactly-once external delivery.
- **I3 No blind replay:** recovery never blindly resends an attempt that may have taken effect. Retry requires demonstrated no-effect, effective adapter idempotency or reconciliation under the contract.
- **I4 No fabricated certainty:** receipts are not truth; attempts/timeouts/cancellation are not success/failure proof; UNKNOWN persists when the evidence is insufficient.
- **I5 Causal reconstruction:** retain principal/audience/time/causal/producer lineage and exact authorized context references; every new derived write traces to committed evidence. Deliberately unretained payloads and legacy gaps are explicit, not reconstructed by invention.
- **I6 Thin surfaces:** adapters translate transport/authentication/presentation; Runtime alone owns semantic admission, context, reasoning and effects. No QQ-specific conversation loop, Memory authority or plugin bypass.

## Execution order and Definition of Done

Families remain A7–A12 for continuity; only the leaf atoms below are executable units. Each implements one coherent boundary and updates its own contracts, validation record and status.
