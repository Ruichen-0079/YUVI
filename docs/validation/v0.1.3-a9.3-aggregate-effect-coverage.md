## Reconciliation and realized ownership

The two partial passes were retained and reconciled rather than restarted. The
supplementary reply-publication lifecycle table/API was removed. Canonical
`effect_intents`, `effect_attempts`, terminal/progress `effect_observations` own
logical/attempt accounting. Migration 023 adds static contracts and bounded
immutable component/seal, speech-plan/segment, audio-result and input-exposure
references. Those domain records do not claim another outcome/dispatch authority.
Conversation messages remain the semantic reply read authority, projected from
ordered components; final seals bind the exact prefix. Source attempts are separate
from reply identity. Exact component replay survives sealing; conflicting content,
source attempt, projection or target payload fails closed.

ProviderRegistry still owns route selection. A logical provider task scopes actual
leaves, with one committed attempt/start per invocation. Input digests, opaque
configuration revisions and safe routing descriptors are retained, not prompts,
credentials, hidden reasoning or raw audio/images. Trusted transport witnesses can
certify pre-call non-start; only that evidence permits policy-approved fallback.
Response loss remains UNKNOWN. A returned invalid response can establish provider
response production without producing valid assistant text. Dots automatic 429/503
retries and its hidden abort-triggered remote cancel request were removed.

Each nonempty projected delta commits component + conversation projection + active
canonical target admission in one transaction before yield. HTTP, voice HTTP, both
SSE routes, internal proactive live subscribers and WebSocket/EventBus downstream
writes claim/start before the actual target write. Terminal/control frames are
accounted; pre-ingress validation and operational read responses are excluded.
Internal EventBus dispatch is computation, not a second transport delivery.
Successful writes establish LOCAL_GATEWAY_WRITE_ACCEPTED, never peer receipt.
Already-admitted components reuse that canonical admission rather than admitting
it again. No ambiguous write is automatically resent.

The existing SpeechSegmenter alone decides segments. Server seals exact prepared
text against committed component spans and explicit markdown/nonspoken omissions.
One frozen NONE/CLIENT_SEGMENTED/SERVER_WHOLE plan owns a reply. TTS uses canonical
provider work keyed to segment/rendering policy; an immutable volatile-audio
availability descriptor commits before forwarding. Playback and subtitle work
commit start before fenced single-use client permissions. Permission/attachment,
PLAYING, completion and subtitle acceptance remain separate evidence. Only current
validated PLAYING establishes DEVICE_REPORTED_PLAYING. None claims human hearing.
Repeated generation registration retains identity; revocation cannot mint fresh
rights for the same request. Restart loses execution rights and never replays audio.

Embodied production dispatch exclusively selects A9. The legacy Runtime record is
only a semantic proposal; the old bridge is not a second dispatch authority.
Versioned generation/expiry/capability permissions distinguish bridge acceptance,
device acceptance, STARTED and COMPLETED. Stale/lost callbacks do not revive work.
No active device owner means explicitly unsupported/no dispatch.

Proactive provider work is admitted after eligibility gates, and external causes
are reused. NO_OP creates no assistant publication. STT uses capture preparation,
not a later finalized receipt as its earlier cause. Vision uses its committed input
receipt/preparation cause. Perception does not automatically become an outward reply.
Finalized/Dream keep their exclusive keyed executors/identities and no generic
Memory queue or duplicate attempt was added. Profile/Person/binding/P8 owners remain
unchanged. Read-text retains A9.2's canonical executor.

## Shutdown and restart

Server preClose seals Runtime ingress/proactive scheduling and new outward work,
invalidates media/presentation rights, drains/fences the shared dispatcher, records
results or UNKNOWN, then tears down plugin/native services and closes the pool.
Forced drain releases the waiting caller while retaining the adapter closure until
it settles. Detached callbacks perform no late SQL or publication. Lease renewal
is same-attempt/fence authority, not retry evidence; loss requests cancellation and
withholds stale output. Hot reload invalidates old device rights and drains Runtime
before replacement. Stateless provider objects have no premature disposal hook.
