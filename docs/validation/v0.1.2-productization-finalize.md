## Limits

History currently projects the most recent 200 repository messages; this PR adds no older-history pagination. The existing 3-second idle polling supports Runtime reconnect and retry. Selected full framing is presentation state for the current mount; restart intentionally returns to half.

Native acceptance covers KDE Wayland with the existing XWayland launcher path, not pure GTK Wayland, Windows or macOS. No new release installer/public artifact was produced. The existing mem0 service reported degraded during the final run; Runtime and private Postgres were healthy. Repairing that independent service is outside these five items. Small-window subtitle pagination uses a conservative glyph budget rather than font-by-font layout measurement.
