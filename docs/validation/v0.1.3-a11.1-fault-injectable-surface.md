# A11.1 deterministic fault surface

Status: **IMPLEMENTED REALITY**. Source parent: `0641ca7e67046752e615f7bd33d06f61b97819c1`. A11.2 remains open; this is not release certification or A12 implementation.

`scripts/conformance/fault-surface.mjs` is framework-independent test infrastructure, with TypeScript declarations. `FaultPlan` intercepts before/after actual owner operations, pauses on explicit barriers, throws once, or reports an IPC checkpoint for a parent to SIGKILL. `faultPort` and `faultPool` forward unchanged to existing owners/connections. Response-loss faults happen after the real operation returns. No timer determines effect certainty; the child watchdog fails a stuck test.

Named boundaries: receipt, manifest, INTENT, ATTEMPT, dispatch-start, external effect, observation, publication, callback, owner revision, shutdown and restart. Tests choose the precise store method/SQL boundary and phase. This does not add production dispatch hooks or another queue.

`SyntheticSurface` forwards bounded private/group transport facts to a supplied existing ingress. Principal, audience and membership fields are hints. It cannot supply conversation, Memory, Person, binding, disclosure, context or retry authority. Current anonymous HTTP has no authenticated membership or upstream dedup contract: duplicate logical keys are tested at Journal/A9's supported seams, not invented from text equality. A12 must implement its authorized adapter translation separately and can reuse these controls.

`ControlledTarget` models APPLIED, PROVEN_NOT_APPLIED, UNKNOWN, CONFLICT, lost responses, explicit idempotency and lookup capability. It is a peer, never an effect admission or retry engine. Explicit barriers delay callbacks; existing dispatcher currentness/lease/shutdown logic decides whether their results remain usable.
